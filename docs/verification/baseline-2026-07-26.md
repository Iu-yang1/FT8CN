## O2 versus O3

Both builds produced identical result counts and hashes, and pure-noise regression produced zero messages. O3 was slower:

| Mode | O2 p95 | O3 p95 |
| --- | ---: | ---: |
| FT8 | 575.074 ms | 1039.436 ms |
| FT4 | 311.350 ms | 563.457 ms |

Release therefore uses O2. Fast-math, target-native instructions and LTO remain disabled.

## Validation scope

Passed host coverage includes pack/unpack, CRC, LDPC/tone consistency, FT8/FT4 synthetic waveform decode, 12/24/48 kHz resampling, CFO/DT/AWGN, crowded overlap, pure-noise false-decode guard, OSD equivalence, request snapshot/live-disk state, frequency clamps, FT8 41/47/50 phases, Q65 A-F capacity diagnostics, Q65A/60 TX-RX and two-frame averaging.

The official standalone `jt9` executable was not discovered, so executable-level cross-oracle was not run. Official vendor source is used directly by the bridge, but that is not a substitute for the missing executable oracle. Android heap/native allocation and device timing are recorded only when an authorized ADB device is available.
