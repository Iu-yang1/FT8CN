# FT8CN 阶段 9 外部阻塞与未完成项（2026-07-29）

以下项目没有被写成 PASS；每项均已完成可在本机执行的替代验证。

- `BLOCKED_SANITIZER`：MSYS2 UCRT64 GCC 16.1.0 不提供 `libasan/libubsan`。已从官方 MSYS2 仓库安装 `mingw-w64-ucrt-x86_64-compiler-rt 22.1.4-4`，包 SHA256 `6882b5c96dade3d94dd13be2675b1912d5a0d482790919ff3aeff4752306e407`，但其 Windows 包只有 builtins/profile/fuzzer，不含 ASan/UBSan 链接库。独立 LLVM 22 的 MSVC runtime 与当前 MinGW/GFortran core 不能安全混链；GNU-target 探针也因缺少对应 MinGW sanitizer archive 失败。WSL 不可用。普通 strict CTest、Fortran runtime checks 和 Android 门禁均通过，但不能替代 sanitizer。
- `BLOCKED_HARDWARE_RIG` / `BLOCKED_HARDWARE_TX`：没有确认接入假负载和安全功率的实体电台，因此不执行真实 PTT、Fake It、Doppler 发射或 USB detach 矩阵。fake rig、loopback rigctld、读回、回滚、watchdog 和 stop 已通过。
- `BLOCKED_NATIVE_HAMLIB_USB_FD`：Android USB host fd 尚未覆盖全部 Hamlib 机型；当前使用已有 Android serial transport 或外部 rigctld，不声称全机型直连完成。
- `BLOCKED_GNSS_FIELD_VALIDATION`：没有在可信室外 GNSS 条件下采集 raw clock 长时数据。NTP 四时间戳、本地 mock、GNSS bias/leap 转换、holdover、时钟跳变和 1000 个 slot 边界已自动化验证；自动 TX 的 500 ms/30 min 健康门禁已接线。
- `BLOCKED_EME_EPHEMERIS_ORACLE`：EME 三种 Doppler 组合和符号已与 WSJT-X 定义对齐，但紧凑 Moon ephemeris 尚未用 JPL/官方指定时刻的高精度方位、距离、range-rate corpus 完整验收。
- `BLOCKED_Q65_EXTERNAL_STREAMING`：本地 AudioTrack RX/TX 已真流式；外部 network/CAT wave transport 没有有界流协议，当前明确拒绝该组合，避免退回完整双 buffer。
- `BLOCKED_PROVIDER_FAILURE_MATRIX`：CelesTrak/SatNOGS 的 304、错误、超限、缓存损坏和离线由 fake transport 覆盖，但未主动破坏公共服务做线上故障注入。
- `BLOCKED_TQSL_EMBEDDED_SIGNING`：TrustedQSL 2.8.6 已完成许可证和依赖审查但未链接 APK；缺少完整证书生命周期、Android Keystore 私钥保护和联合 native 安全审计。当前仅导入外部 TQSL 已签名 `.tq8`。
- `BLOCKED_LOTW_ACCOUNT`：没有使用用户证书、密码或真实 QSO 做在线上传。官方响应格式、accepted/rejected/timeout、幂等和重试由 mock 覆盖，不上传未签名 ADIF。
- `BLOCKED_DEVICE_UI_UNLOCK`：连接设备受安全锁屏和厂商启动确认页限制。Headless Debug/Release instrumentation、APK 安装和 native 矩阵通过；真实 Compose 点击/旋转/进程恢复未冒充通过。
- `BLOCKED_COMPLETE_COMPOSE_MIGRATION`：现代 Material 3 六入口工作台已实现，但默认 launcher 与少量完整操作台仍保留 legacy fallback。为避免丢失成熟功能，没有为了形式删除旧页面。
- `BLOCKED_BASELINE_PROFILE_GENERATION`：因真实页面 benchmark 被锁屏阻止，未生成未经验证的 Baseline Profile。
- `BLOCKED_TRANSLATION_COMPLETENESS`：默认中文新增资源尚未补齐 Greek/Japanese/Spanish/Chinese alternate resources。严格 lint 只对该既有 `strings.xml` 做路径级例外，任何其他文件的新缺失翻译仍会失败。

当前不存在 `BLOCKED_DEVICE`、`BLOCKED_ORACLE` 或 `BLOCKED_Q65_STREAMING`：授权真机、官方 jt9 和本地 Q65 300 秒生产流式门禁已经通过。
